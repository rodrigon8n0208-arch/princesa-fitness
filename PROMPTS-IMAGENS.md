# Prompts das imagens — Princesa Fitness

**Onde salvar:** `src/assets/img/site/`, com **exatamente o nome indicado** em cada item
(a extensão pode ser .jpg, .png, .webp ou .avif). O site troca a imagem sozinho no próximo
`npm run build` / `npm run dev`. Enquanto o arquivo não existir, fica a imagem provisória.

Todos os prompts já trazem o estilo da academia real (teto preto com fitas de LED, painéis de luz
vermelhos, piso preto com faixas vermelhas, máquinas pretas) e pedem **sem texto e sem logos**,
porque geradores de imagem inventam logos errados. As imagens dos posts do Instagram (seção
"Acompanhe a rotina") continuam como estão.

> Dica: gere em alta resolução (mínimo indicado) e, se o gerador tiver opção de proporção,
> use a mesma do item. Para a `hero`, depois rode `npm run og` para atualizar a imagem de
> compartilhamento do WhatsApp/redes.

---
